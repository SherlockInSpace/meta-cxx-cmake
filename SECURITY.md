# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately using one of the following:

- GitHub private vulnerability reporting:
  <https://github.com/SherlockInSpace/meta-cxx-cmake/security/advisories/new>
- Email the maintainer: Ryan Sherlock <ryan.m.sherlock@gmail.com>

Include a description of the issue, the affected recipe or file, and steps to
reproduce where possible. You will receive an acknowledgement, and a fix or
mitigation will be coordinated with you before any public disclosure.

Vulnerabilities in the upstream software packaged by this layer's recipes
should be reported to the respective upstream projects.
